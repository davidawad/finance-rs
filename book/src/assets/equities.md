# 4. Equities

Catalog mapping: [§4 Equities](../../../../../../../docs/finance-rs/catalog.md#4-equities).

The `equity` module groups dividend-discount and residual-income models,
implied returns, operating ratios, multiples, comps, and Graham screens. The
`corp` module provides enterprise-to-equity bridges, WACC, CAPM, and DCF
building blocks used by company-level valuations.
