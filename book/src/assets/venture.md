# 12. Venture

Catalog mapping: [§12 Venture](../../../../../../../docs/finance-rs/catalog.md#12-venture).

`vc` covers SAFE and note conversion, cap-table dilution, anti-dilution,
option-pool adjustments, pro-rata reserves, and exit waterfalls. Security
terms are data inputs so rounds can be represented without embedding a
single financing template in the library.
